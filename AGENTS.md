## Agent skills

### Issue tracker

Issues live in GitHub Issues for `FasalZein/pi-hooks` (use the `gh` CLI). The specification is the issue labeled `spec`; tickets reference it and list their blockers as `Blocked by #N`. Apply `ready-for-agent` to tickets an agent may pick up.

### Domain docs

Single context. The glossary is `CONTEXT.md` at the repo root; decisions live in `docs/adr/`. Read both before changing terminology or architecture. Use glossary terms verbatim in code, tests, issues, and commits.

### Historical archive

The wiki vault (project `pi-hooks`) is a read-only archive of earlier PRDs and slices. Search it for prior intent; never write to it.
